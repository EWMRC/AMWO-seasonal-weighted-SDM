# Cross-seasonal species distribution models better facilitate habitat conservation for a migratory bird
 
Currently under review. Contents of this repository are as follows:
- methods: code used to create the seasonal models used in the Woodcock Priority Area and Siting (W-PAST) tool, available at https://woodcock.shinyapps.io/W-PAST2/. Subdirectories contain data and code for evaluating machine learning frameworks, creating the breeding and migratory SDMs, running predictive layers on high performance computing clusters, andcreating a spatial decision support system using Shiny. 
- figures_results: code used to create the manuscript figures and generate the statistics included in the results
