# Cross-seasonal species distribution models better facilitate habitat conservation for a migratory bird
 
Currently under review. Contents of this repository are as follows:
- methods: code used to create the seasonal models used in the Woodcock Priority Area and Siting (W-PAST) tool, available at https://woodcock.shinyapps.io/W-PAST2/. Subdirectories contain data and code for creating the breeding and migratory SDMs, as well as creating the spatial decision support system. 
- figures_results: code used to create the manuscript figures and generate the statistics included in the results
